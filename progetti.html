Pagina ricetta

Tecnologie: HTML5, CSS, Git.


Una pagina web che presenta una ricetta di cucina. Esercizio di markup semanticoapplicato a un contenuto reale: titolo principale, sezioni distinte per ingredienti e procedura, lista ordinata per i passaggi, immagine del piatto finale con didascalia.


Cosa ho imparato: scegliere il tag giusto in base al significato del contenuto e non all'aspetto visisvo. Differenza tra <section> e <article>. Uso di <figure>e <figcaption> per le immagini con didascalia.

Card di presentaazione

Tecnologie: HTML5, CSS, Font Awesome.


Un biglietto digitale con nome, ruolo, foto profilo e link ai social. Esercizio su tag semantici, link esterni con target="_blanck", immagini con alt significativo. Prima esperienza con le icone di Font Awesome.


Cosa ho imparato: organizzare l'informazione in poco spazio mantenendo gerarchia visiva. uso degli id per anchor interne. Pattern header / main / footer su una singola card.

Portfolio personale

Tecnologie: HTMLS5, CSS3, google Fonts, Font Awesome, Git, GitHub Pages.


la pagina che state vedendo. costruita da zero in cinque giorni, partendo dal markup HTML e arrivando alla stilizzazione CSS completa con box model, pseudo-classi, pseudo-elementi e tipografia ragionata. Pubblicata online su GitHub Pages al termine della prima settimana di corso.


Cosa ho imparato: progettare una pagina pensando alla gerarchia dei contenuti prima del design. Stilizzare in modo consapevole partendo da un reset CSS. Gestire una repository Git con commit descrittivi. Pubblicare un sito statico online
